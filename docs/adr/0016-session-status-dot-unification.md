# 标题行会话状态点统一，独立链路点退役

2026-10-03 机主看到「会话列表显示绿色、正文标题旁却是蓝色」后定夺：两种圆点在同一直觉位置承担
不同事实，容易把「会话空闲」误读成「链路状态不一致」。正文标题行改为只回答当前会话的状态，
不再另画 PC 桥链路点。

## Decision

- 标题行保留一颗**会话状态点**，与 Status Glow 共用四档语义：工作中＝蓝、等待确认＝琥珀黄、
  空闲＝绿、出错＝红。
- Bridge Link 未连接（连接中、重连中、未配置或停用）时，旧会话状态不可信，状态点统一压成灰；
  恢复后回到当前会话状态色。链路异常不再有独立圆点。
- 「自动」档下，状态点始终跟随正文当前显示的会话。
- Agent 空态没有会话状态，不画点；既有会话列表标记本轮保持不动。
- 主屏主页与设置页仍以文字显示 Bridge Link，三处“同一份链路事实”不再靠背屏圆点成立。

## Consequences

- 一处圆点只表达一个产品问题：「这个会话现在怎么样」。
- 断线仍可辨，但通过灰档压过旧状态，不再与工作中蓝色争抢同一视觉语言。
- 票 #165 的“背屏独立链路状态点”和 ADR 0012 中“连接过程归会话标识行状态点”的分工被本决定取代；
  历史 ADR、已关闭票与实机证据保持原貌，仅以本 ADR 作为现行口径。
