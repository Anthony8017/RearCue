# 手机新建 Codex 对话显式选择强度与权限

2026-10-16，机主经 grill-with-docs 确认 Q1–Q10 后显式调用 implement-spec 授权实现。实施中，尚未完成验收或部署；完整规则与验收见 [spec 0036](../specs/0036-codex-conversation-options.md)。

手机主屏新建 Codex 对话时，可选择电脑允许的全部执行权限档位，包括允许时的“完全访问”，并看到每档的访问范围与确认行为。新建窗口直接显示模型、思考强度及权限；所选强度与权限持续作用于这条对话的后续追问，手机此次选择不改电脑默认值或其他对话。

每次新建以所选项目在电脑端的新对话默认设置为起点，手机本次改选不记作下次默认。已手选的档位因换模型或项目而失效时，保留任务文字并要求重选有效值后才创建。完全访问在选项旁说明影响，明确选择后随创建生效，不追加确认弹窗。

新建窗口保持机主填写期间所见的组合，电脑后台默认值变化不能静默替换它。创建后的设置属于该条对话；机主在电脑明确改动后，手机后续追问以修改后的实际设置为准，创建时旧值不再覆盖新值。

此前 ADR 0017 / spec 0024 将远程输入固定绑定到逐项批准。机主需要从手机明确决定本条对话的权限，因此以显式选择修订该固定限制；电脑自身的权限限制继续生效。Remote Approval 开关仍只控制批准入口，不能被当作会话权限选择。

此决定只改变上述权限边界，不扩展为任意电脑控制，也不改变手机解锁、桥鉴权、断线禁发及未知状态不自动重发的既有约定。受限权限实现按本决定修订，实际完成度以 spec 0036 的验收记录为准。
