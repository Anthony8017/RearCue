# Remote Codex Conversation：主动发起面取代「除批准外只读」

外部 Codex 远程创建入口在 provider/model 切换后会产生失败空会话，而 RearCue 只能看见、不能发起或收口。
2026-10-03 grilling 定案：手机主屏新增长期的 Remote Codex Conversation，可新建、追问、停止 Codex 会话，
并只允许删除「发起失败且无正常回复」的空会话；正常会话仍只在电脑端归档。

此决定**部分取代 ADR 0009**：「发 prompt 永不做」废除，但任意按键、文件管理、任意电脑控制仍禁止；
发起 prompt 不等于预批准，文件修改和命令执行继续逐项走 Codex 原有批准。远程发起、停止与删除必须受
桥访问凭据保护，断线时不排队、不自动重试，发送状态未知时由机主确认后再手动重试。
