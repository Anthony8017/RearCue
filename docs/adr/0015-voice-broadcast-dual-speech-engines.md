# 15. Voice Broadcast 双语音引擎：离线 Kokoro 默认、系统 TTS 可选

日期：2026-10-03
状态：已接受（grilling 定案）

## 背景

Voice Broadcast 要朗读 Agent Task Completion 的回复正文。机主要求选择“公认免费最好”的中文 TTS，
并在免费、离线、隐私和自然度之间按此优先级取舍；同时明确要求保留手机系统自带 TTS 作为可选引擎，
避免为一个 300–350 MB 的模型强制付出下载和存储成本。

## 决定

| 决策点 | 定案 |
| --- | --- |
| 默认引擎 | Sherpa-ONNX + Kokoro 中文/英文离线模型 |
| 可选引擎 | 手机系统自带 Android TTS |
| 成本 | 默认引擎首次启用且机主确认后下载约 300–350 MB；下载后完全离线 |
| 隐私 | 默认引擎不上传回复正文；系统 TTS 的数据处理随手机所选引擎 |
| 故障回退 | 默认引擎暂不可用时，明确提示后临时使用系统 TTS 播完当前队列 |
| 双故障 | 两引擎均不可用时不阻塞 Agent 结果，只保留允许响起的提示音与通知 |
| 设置 | 两引擎分别记住中文音色；语速共用 0.5×–2.0× 全局档位 |

## 后果

- 以约 300–350 MB 的一次性存储换取免费、离线、隐私优先的中文自然度；下载只在总开关开启且仍选择默认引擎时发生。
- Kokoro 权重为 Apache 2.0，Sherpa-ONNX 为 Apache 2.0；构建和发布时仍须随实际打包方式保留许可证与来源说明。
- 系统 TTS 不是质量保证，而是零下载、兼容旧设备和故障回退路径；其听感、联网与隐私由手机当前语音引擎决定。
- 两套音色目录不共用编号，避免切换引擎后声音设置错配；语速保持全局一致，降低设置复杂度。
- 这是容量、隐私、自然度与设备兼容性之间的明确取舍；若未来模型体积或中英文听感显著改善，可替换默认模型但不取消系统 TTS 选项。
