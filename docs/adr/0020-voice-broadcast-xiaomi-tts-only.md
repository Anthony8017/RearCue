# 20. Voice Broadcast 仅使用小爱语音引擎

日期：2026-10-04
状态：已接受（机主定夺，取代 ADR 0015）

## 背景

ADR 0015 曾提供离线 Kokoro 与系统 TTS 两套引擎，并包含模型下载和故障回退。机主明确要求
仅使用小爱语音引擎，删除其他引擎选项，避免设置复杂度和额外的模型下载、存储成本。

## 决定

| 决策点 | 定案 |
| --- | --- |
| 唯一引擎 | 小爱语音引擎 `com.xiaomi.mibrain.speech` |
| 设置 | 不提供引擎切换或离线模型下载；只保留小爱音色、语速和音调 |
| 故障处理 | 小爱语音不可用时提示但不回退到其他语音引擎，不阻塞 Agent 结果 |
| 兼容 | 旧设置中的离线/系统引擎值一律归一为小爱语音 |
| Android 可见性 | manifest 声明 `TTS_SERVICE` 与小爱语音包，确保 `TextToSpeech` 可以绑定 |

## 后果

- 设置页只显示“小爱语音”，不再出现离线推荐、系统 TTS 或模型下载选项。
- 听感、联网和隐私由手机上的小爱语音引擎决定。
- 如果小爱语音引擎缺失、被禁用或绑定失败，语音播报保持安静并显示一次故障提示。
- 语速、音调和小爱音色仍可调整，避免把语音偏好一并删除。
