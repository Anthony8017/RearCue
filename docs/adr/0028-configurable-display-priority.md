# 28. 自动切页共用可配置显示顺序

日期：2026-10-13
状态：已接受，机主确认并开始。

白名单应用可开启优先通知，新通知将通知页加入自动显示仲裁。设置页以拖动方式排列
待确认、待答问题、优先通知、语音播报，默认按此顺序；最高有效项决定内容页和对应会话。
排列决定显示，不改变投送资格、批准事实、问题事实或语音播放。

优先通知不是限时插队：胜出后通知页成为返回目标，直到机主手动切页。被挡住时仅保存
触发 key，移除取消、多条合并；真实新到达才能触发，更新和快照不能制造跳转。

本决定修订旧规范中待确认固定最高的限制。保留 Codex 待答被动提示，保留原有投送和
退屏条件，不用排序设置引入新投送路径。完整产品判例见 spec 0034。
