# 会话列表是对话的底页

日期：2026-10-11
状态：已接受（机主定案）

背屏会话列表原先盖住对话。机主确认这层关系反了：列表是对话底下的那一页，对话整页画在列表上。点按、选择、排序、默认先出列表，以及开关列表的样子都不变；停稳后仍只看见其中一个。

## 取舍

- 不改成列表和对话同时可见，也不把列表收成一条。背屏一次只看其中一页。
- 不把通知页也放到列表上。列表和通知来回仍不经过对话。
- 主屏选会话不动。

## 后果

- 看对话时，对话整页盖住底下的列表。看列表时，列表自己是底页，不再盖住对话。和通知页的来回仍不露出对话。看得见的操作不变。
- 与 spec 0016 当时「全窗浮层盖住对话」的说法相反；该 spec 的操作语义继续有效。
