# Status Glow 与会话状态标识对齐

2026-10-04 机主定夺：Status Glow 不再保留独立配色，改为与 Session Status Indicator 共用状态基础色；空闲是否亮灯带同时读取会话已阅状态。这样背屏一眼看到的颜色只表达同一套产品语义，不再出现“状态点是蓝色、灯带却还是绿色”的分裂。

## Decision

- 工作中＝中性浅灰、缓慢流动；等待确认＝绿、呼吸；空闲没阅＝蓝、静止低亮；出错＝红、静止；断链＝灰、静止并压过其他状态。
- 空闲已阅不显示 Status Glow。背屏点按会话正文才完成已阅回执；点标题、会话列表或空白不标已阅。
- 空闲没阅灯带在正文点按后约 0.6 秒渐灭；新的完整没阅回答或状态变化重新点亮。工作中、等待确认、出错不因正文点按熄灭。
- Status Glow 与状态标识共用基础色，但不共用形状、亮度、光晕和动效参数。系统“减少动态效果”只停止 Spinner，不改变灯带的状态含义。
- 本 ADR 取代 ADR 0019 中“Status Glow 既有五档色不变”的部分，并更新 ADR 0012/0016/0018 的颜色与空闲显示口径。

## Consequences

- 灯带现在也回答“空闲结果看过没有”；已阅空闲回归无信号，避免常驻蓝光变成第二个未读提示。
- 正文点按是已阅与渐灭的共同边界，标题、列表和空白操作不会误清状态。
