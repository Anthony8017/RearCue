# 会话状态标识改为 Spinner 与蓝/绿重排

2026-10-04 机主定夺：把标题行与会话列表原来的彩色状态点统一改称 **Session Status Indicator（会话状态标识）**，并把“工作中”改成 Codex Desktop 同观感的浅灰 Spinner。这样“正在干”靠动作识别，蓝色只留给“空闲但结果没看过”，绿色只留给“等待确认”。

## Decision

- 标题行与会话列表使用同一投影：工作中＝浅灰 Spinner、等待确认＝绿点、空闲没阅＝蓝点、空闲已阅＝不画、出错＝红点。
- Bridge Link 不是“已连接”时，无论旧状态与已阅状态如何，统一显示灰点；会话空态与「自动」行不画。
- Spinner 参考 Codex Desktop 26.924.6891.0 前端资源的视觉契约：30% 底环、270° 前景弧、顺时针 360°、周期 2 秒、`steps(60, end)`；系统关闭动画时静止。工作态采用参考图的中性浅灰，不再使用蓝色。
- 会话状态标识与 Status Glow 分工：前者回答单个会话“现在怎么样、看过没有”，后者回答背屏整体状态。两者不再强制同色；Status Glow 的既有五档色与动效不变。
- 本 ADR 取代 ADR 0016 与 ADR 0018 中关于状态点颜色、形状和标题行空闲显示的部分；排序、断链压过、已阅事实来源等其他规则不变。

## Consequences

- 颜色不再单独承担全部语义：工作与没阅都偏灰/蓝系，但 Spinner 的运动和圆点的静止构成第一识别线索。
- “会话状态点”成为历史词，现行文档与代码统一使用“会话状态标识”。
