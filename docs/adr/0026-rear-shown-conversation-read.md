# 背屏露出当前对话即已阅

日期：2026-10-11
状态：已接受（机主定案）

背屏不再只在点按正文时把会话标成已阅。完整新回答一完成就是没阅，哪怕这条对话正盖在列表上；电脑上来源正文正开着，则仍算已阅。已阅两端共享。主屏不改。

## 取舍

- 背屏只标当前露出的这一条。从列表点进它，或点空白、再点标题让对话整页盖上来，都算已阅。
- 对话已经盖住列表时，点正文、点标题、滑正文、切到通知，也算已阅。
- 只滑列表、在通知页上接着点、自己翻页、播报和自动滚动，都不算。
- 正看着它答完也先出蓝点，再有一次上述手动动作才消失。之后又答完，重新没阅。
- 不把绿点、红点、工作中的转圈改成已阅信号。

## 后果

- 与 ADR 0018「正文正在展示时新回答继续算已阅」，以及 ADR 0021「只有点按正文才已阅」相反。颜色、约 0.6 秒渐灭和两端共享仍按原口径。
- 主屏仍是正在看这条且停在最新回答才算已阅。
- 来源软件的正文正开着时，新回答不因背屏正在显示而变成没阅。
