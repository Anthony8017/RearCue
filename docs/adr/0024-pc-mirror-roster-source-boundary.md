# 24. 镜像名单与来源归档分开管理

日期：2026-10-05
状态：已接受；整套设计已获机主确认，实现按 spec 0030 推进。

来源软件的归档、删除表示原对话是否存在且可镜像；机主在 PC 桥中的加入、移出只表示是否允许它进入手机镜像名单，两者分别记录。PC 桥持久保存机主的移出选择，持续停用该对话的手机镜像、等待插队、提醒、播报和对话操作入口，直到机主手动恢复；新活动、重启、改名或归档后再取消归档均不覆盖该选择，来源归档与删除仍优先于镜像加入。

复用来源归档来表达移出，会把手机镜像管理变成原对话管理；只临时过滤列表，会使后续活动重新带回已移出的对话和提醒。另存镜像资格使四来源共用一致规则，并保留原软件的会话生命周期含义。

已确认需求与后续未决项见 [spec 0030](../specs/0030-pc-mirror-registration.md)。
