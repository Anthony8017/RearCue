# Voice Broadcast 媒体键单击/双击语义

2026-10-04 机主定夺：标准播放/暂停控制不再以单击丢弃整批播报，改为单击暂停/继续、双击停止并清空。该口径适用于耳机、线控及其他标准媒体控制；“下一首”继续只跳过当前内容。

## Decision

- 单击正在播放的 Voice Broadcast 立即暂停；超过 500ms 后再次单击继续。
- 500ms 内第二击视为双击，立即进入 Broadcast Discard，清空当前内容和所有已排队内容；紧随其后的第三击在窗口内忽略。
- 暂停保留当前内容与队列。恢复时从当前句开头继续，不重播提示音；无法精确到半句续读时以整句重播为界。
- 单击暂停时让先前被压住的其他媒体恢复；继续播报时重新接管声音。暂停期间新到结果排队等待，不自动打断暂停。
- 来电等系统声音打断只算临时中断，不计单击/双击；应用重启后不恢复旧的暂停批次。
- “下一首”语义不变：只跳过当前整条并继续后续内容。

## Consequences

- “再次单击”仅在双击窗口外才表示继续；窗口内第二击优先识别为双击丢弃。
- 设置页提示与产品口径从“单击停止”改为“单击暂停/继续、双击停止并清空”。
- 状态机明确区分 Broadcast Pause、Broadcast Discard 与 Waiting-for-Approval 的清空。
