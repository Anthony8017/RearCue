# Spec 0031：PC 桥连接状态集中显示

日期：2026-10-06
状态：grill-with-docs 已收口；已实现，184 项针对性测试与 APK 构建通过，已安装手机；正常连接时主屏顶部布局与唯一状态入口已实机核对。

## 已确认

- 主屏只在主页 Agent 镜像卡顶部显示一处实时连接状态，桥地址及现有地址操作也放在卡顶部。
- 总览卡不再重复显示桥连接状态；桥连接状态不再与会话名称、会话工作状态拼成一行。
- 地址测试结果仅表示当次测试，成功反馈使用「地址测试通过」，不再称「已连上这台电脑的桥」。
- 背屏保留既有断线提示：链路未连接时，会话状态标识以灰点覆盖旧状态。

## 连接状态

| 场景 | 主屏文字 |
| --- | --- |
| 手机长轮询正常 | 已连接 |
| 已设置地址、首次连接尚未成功 | 连接中 |
| 请求失败，包括连续失败超过约 150 秒 | 已断开，正在自动重连 |
| 镜像开启但未设置地址，或收到清地址通知 | 未设置地址 |
| 机主关闭 Agent 镜像总开关 | 已关闭 |

总开关关闭与未设置地址并存时，优先显示已关闭；卡顶部地址入口仍可使用。连接状态不以当次地址测试结果为判据。

## 源码核对

修改前两处实时状态实际都在主页，且共用 AppState.bridgeLinkStatus。地址下的成功文字来自保存时一次地址探测，断线后不随实时状态更新，可误导机主；本次确认源码存在此路径，未复现机主现场。

原 BridgeLinkStatus.DISABLED 混合未配置地址、总开关关闭、连续连接失败约 150 秒；超时降级后仍自动重连。本次将持续失败上报为 DISCONNECTED，停止维护链路才报 DISABLED。主屏结合总开关、地址配置与此实时事实区分文案；背屏继续消费同一链路事实，未连时压成灰点，长时间断线的灯带停止照旧。

本 spec 取代 ADR 0016 与 spec 0019「主屏两处显示」及 spec 0019 将超时失败称为「未配置或已停用」的旧口径。PC 托盘仍按现有规则显示电脑侧观察到的状态。

## 验收范围

- 正常连接、首次连接、短暂断线、长时间失败、未设置地址、手动关闭、自动恢复分别检查状态文字。
- 保存并测试成功后再断线，页面不得继续把旧测试结果称为实时「已连上」。
- 清除地址后，卡顶部仍能看到状态和地址填写入口；保存、测试、清除与电脑推送地址继续可用。
- 主页只有一处实时连接状态，背屏断线仍显示灰色会话标识。
