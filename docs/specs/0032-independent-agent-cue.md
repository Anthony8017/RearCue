# Spec 0032：Agent 提示音与语音播报独立

状态：机主已最终确认（2026-10-09）；代码与本地测试已完成，实机听感待验收。

## 已确认

- Agent Cue（提示音）与 Voice Broadcast（朗读）各有独立开关，可只响提示音、不朗读，也可只朗读、不响提示音。
- 提示音覆盖主会话需要机主回答或批准、新完成结果、最终失败三类事实；不与实时输出或内部子 agent 的事件混同。
- Agent Alert 仍指通知栏提醒及可选震动，不响铃；与上述两个声音功能分别独立。
- 升级时原语音播报开关开启者，提示音与朗读都开启；原来关闭者都关闭。新安装两个开关默认关闭。
- 正在朗读时新待答事项不打断当前整条；当前整条结束后，待答优先于其余排队结果，提示音在对应内容前响。仅提示音开启时，新事项到达即响。
- 仅提示音开启时，耳机播放／暂停键不控制提示音；原有朗读媒体控制保持不变。
- 提示音尊重手机的静音和勿扰设置，不强行突破。
- 待答、完成、失败使用同一提示音；连续多个有效事项逐件响，同一事项重复送达不重复响，未答问题不定时催促。
- 仅提示音不触发语音播报的跟随或回屏；待答事项原有的背屏显示与 Agent Alert 提醒规则照旧。
- 打开提示音开关时不补响此前已有的待答事项或结果，只处理开关开启后的新事项；历史回放同样不响。

## 验收边界

| 提示音 | 朗读 | 新有效事项的声音行为 |
| --- | --- | --- |
| 关 | 关 | 无声音；Agent Alert 和背屏原有规则照旧 |
| 开 | 关 | 到达时只响一次提示音，不因声音切换背屏 |
| 关 | 开 | 仅按现有优先级朗读，不响提示音 |
| 开 | 开 | 对应内容朗读前响一次提示音；当前整条不被新待答打断 |

同一事项的开启状态变更不应造成重复提示；仅提示音不受媒体键控制，语音队列及其配套提示音仍按原有暂停、跳过规则处理。系统静音、勿扰时提示音服从系统策略，不要求突破。Agent Alert 的通知栏及可选震动开关不兼作提示音开关。

实现保留旧语音开关作为朗读设置，并新增独立提示音设置；不改变 Agent Alert 通知及背屏待答呈现。未安装到手机，本地测试不能替代实机响铃、静音与耳机控制验收。
