# Spec 0035：背屏长按通知图标，消除该应用全部划得掉的通知

状态：2026-10-13 grill-with-docs 收口，Q1–Q33 均按推荐确认，机主已「确认并开始」。

## 行为

- 只在背屏上看得到的通知图标上长按。一枚大图标和多枚网格一样。
- 按下后不马上变小。确认是在按住后，只有这枚图标连同数字略缩小，旁边先不动。
- 约半秒一到，就定下要清的通知，不必再松手。只清这枚图标代表的、下拉通知栏里划得掉的通知。划不掉的留下，不先消失再冒回。图标没代表的不动。半秒之后新来的留下，并正常出现。
- 结果还不确定时，图标停在缩小状态。全部清掉：缩小直接接上现有的缩小淡出，旁边再滑去补位；「+N」里补上来的用现有出现动画。最后一枚仍等演完再离开背屏。没清光：恢复大小，数字改成剩下的；要换位就滑过去，不先播放消失。一条都没划掉就恢复原样。
- 长按期间角标不倒计时。不闪光，不震动，不响，不写字。不弹确认，不能在背屏撤销，不加开关。
- 半秒前在图标上松开，仍是短按：打开最新一条详情，只消除那一条。
- 半秒前手指移出这枚图标，滑到空白、「+N」或别的图标，只取消，不打开详情，不切页。只有一开始就按在空白或「+N」上，才按现在的点空白处理。
- 手指没动、图标自己换位或轻微挪动，仍算按下的那个应用。
- 半秒之后松手、移开、换页或退出背屏，都不取消。动画可以不看完，定下来的通知仍清掉。
- 手指不松开，不算按住补位滑过来的图标。松开后可以按下一枚，前一枚还在消失也可以。
- 详情页不能长按清。先收起详情，再长按图标。锁屏同样可用。
- 主屏不新增长按。按住时的缩小只有背屏有。通知真正变化后，主屏用现有出现、消失和移动动画跟着变。

## 验收

- 本地测试覆盖：划得掉的才撤销、划不掉的留下、不打开详情、详情开着不响应；半秒前松手是短按、移出取消、手指没动不取消、半秒后不再取消。
- 实机仍需看：缩小是否接上退场、补位是否顺滑、划不掉的通知是否完全不闪。
