# Spec 0025：Agent 会话页顶部标题覆写与正文渐隐

状态：已与机主 grill 收口（2026-10-04，两轮 Q1–Q11，frontier 空）；代码已落地，实机验收待跑。

术语采用 CONTEXT.md 的 Agent Mirror、Session Title、Session Picker、Prompt Bubble、Mirror Text Size、Corner Avoidance、Detail View 与 Title Fade Band。

## Problem Statement

Agent Mirror 会话页目前把会话标识行固定在屏幕顶部，正文从标题下方开始。标题行即使只保留主行，也会占掉一条正文行的垂直空间；机主希望正文尽量多、标题不要把正文顶开。

这次只改 Agent 会话正文页，不把通知详情（Detail View）混进来。

## Desired Experience

1. 作为机主，我想让正文从屏幕最上沿开始排，以便同一屏看到更多回答。
2. 作为机主，我想让标题覆盖在正文上方并始终清楚，以便随时知道当前会话、看到状态并进入会话列表。
3. 作为机主，我想让正文滚到标题附近时逐渐变淡，以便标题可读而正文仍然连续。
4. 作为机主，我能接受标题下方偶尔有半行被渐隐压住，以换取更多正文。
5. 作为机主，我希望提问泡、回答和代码块滚到标题下时表现一致，以免顶部忽明忽暗。
6. 作为机主，我希望短回答仍然舒服地居中，长回答才充分利用顶部空间。
7. 作为机主，我希望角部避让开关打开时标题也不缺字，关闭时按现有“贴满认缺角”口径。
8. 作为机主，我希望通知详情完全不动，以便这次改动只影响 Agent 阅读面。

## Product Contract

- **范围**：只改 Agent Mirror 会话页正文阅读面。Session Picker、主屏列表、Detail View、Icon Set、充电背景和 ↓ 按钮不改。
- **顶部结构**：正文滚动区上界贴屏幕避让线；会话标识行覆盖在顶部，不再为标题预留独立正文行。标题仍为单行，超长尾部省略。
- **标题可读性**：标题文字与会话状态点始终清楚、常驻；点标题仍打开 Session Picker，状态点语义不变。
- **Title Fade Band**：标题下方约一行正文高度使用黑色到透明的渐隐过渡。正文可以滚入该区域，允许半行被压住；不做硬分割线。
- **统一渐隐**：Prompt Bubble、agent 输出、普通 Markdown、代码块等所有正文内容滚入渐隐带时采用同一观感。
- **短内容**：内容不足一屏时仍整体优先垂直居中；长内容撑满后可向上滚入标题渐隐带。
- **角部避让**：Corner Avoidance 继续是同一开关；开启时标题、正文与会话列表都避开圆弧，关闭时都按贴满口径。
- **字号**：Mirror Text Size 三档语义不变，本次不改字号、行距或 Session Picker 行高。

## Acceptance

- 标题贴顶时正文不再多占一条固定标题行；长回答可见内容增加。
- 标题、状态点和标题点击入口在正文滚动、实时跟随和历史回看中都保持可用。
- 标题下滚过的正文呈连续渐隐，没有硬切边；不同正文内容类型表现一致。
- 短内容仍居中；长内容可滚到标题后方并渐隐。
- 打开 Corner Avoidance 后标题不进圆弧缺字区；关闭后按默认贴满口径。
- Detail View 与 Session Picker 的版式、行高和交互不变。

## Implementation Status

- `AgentReadingText` 的滚动视口改为贴顶全高；短内容仍按标题下缘以下的可用区居中，长内容可滚入标题覆写区。
- `AgentMirrorView` 先画正文，再画黑色到透明的 Title Fade Band 与标题层，标题点按和顶部拖动手势保持原语义。
- 标题带只取单行标题高度；渐隐带取一行正文高度。Corner Avoidance 开时标题顶部同步避让。
- Agent 空态沿用同一标题几何与角部避让口径；Detail View、Session Picker 和字号档位未改。
- 测试状态：`gradlew test` 全绿（109 个任务）。实机需复核长文滚入渐隐带、标题点按、短内容居中和开关两档。

## Out of Scope

- 通知详情（Detail View）的标题、正文和居中规则。
- Session Picker 的条目行高、字号和排序。
- Mirror Text Size 新档位、自定义滑杆或系统无障碍缩放。
- 实时跟随/历史回看策略、跨会话翻页、搜索和远程批准流程。
- Status Glow、会话状态点颜色语义与会话已阅规则。

## Decision Rounds

**R1（2026-10-04）**
- Q1 页面范围 → 只改 Agent Mirror 会话页。
- Q2 更多正文的几何含义 → 正文顶到上方，标题覆盖，不保留标题独立正文行。
- Q3 渐隐对象 → 正文滚入标题区域渐隐；标题始终清楚。
- Q4 标题与状态点 → 常驻、标题可点开 Session Picker。
- Q5 取舍 → 接受标题附近半行渐隐，优先正文密度。

**R2（2026-10-04）**
- Q6 贴顶/圆角 → 标题跟随 Corner Avoidance；关贴满，开避让。
- Q7 渐隐带高度 → 约一行正文高度。
- Q8 渐隐观感 → 黑色到透明遮罩，不用半透明标题带。
- Q9 覆盖内容类型 → 提问泡、agent 输出、代码块等全部一致。
- Q10 短内容排版 → 仍整体优先垂直居中。
- Q11 边界 → 不加硬分割线。

Frontier 空。
