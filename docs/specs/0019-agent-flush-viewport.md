# Spec 0019：Agent 版心贴缘（会话页 + 会话列表）与角部避让开关

状态：已与机主 grill 收口（2026-09-30，三轮 Q1–Q9，frontier 空，见文末「决策轮次」）；
**代码已落地**（票 #194，JVM 判例全绿：贴缘视口本机/顶带/无带、整列角部内缩、开关关＝零避让、
开关开＝弧区回归、core 默认关＋幂等；实机验收链待跑）。
本 spec **反转 spec 0017 的边距档**（Agent 页右距 16dp、上下最小 8 物理 px、左缘带侧 8px 漂移余量），
**不触碰 spec 0011 的「文字不进相机带」**（左界改为贴带右缘，仍不进带）；
**通知详情（Detail View）零改动**——贴缘范围只含 Agent 会话页与会话列表
（批准浮层是 Detail 家族的卡片面，不在贴缘范围，留痕）。
CONTEXT.md 已回填（Agent Mirror 词条版式段改写 + 新词条「Corner Avoidance」）。
决策依据：机主原话「右侧和上下都紧贴边缘，左侧紧贴摄像头都不留」「两个页面我是说 会话列表 和
会话详情」「7 这两个做成选项」「8 默认贴满」。

## Problem Statement

Agent 会话页（Agent Mirror）与会话列表的阅读版心四边都有留白，机主觉得浪费：

- 实机（背屏 904×572、density 2.8125）现状：左缘 = 相机带 296 + 漂移余量 8 = **304px**，
  右距 **45px**（16dp），上下各 **8px**；版心宽 555px，仅占无带可用宽 608px 的 91%。
- 机主要的是**每行多显示字**（版心最大化），不是视觉层铺满——背景层 spec 0009 起早已铺满含带。
- 四角约 5.5mm 大圆角（r=97px）完全贴缘时，冲进弧区的行会被切角缺字——机主拍板
  **默认贴满认缺角**，避让与否交用户开关。

## Solution

- **版心四边贴缘**：左界 = Camera Band 右缘（本机 296px，字不进带）；右/上/下 = 各自的
  cutout 避让线（本机无带即屏缘 **0px**）。设计留白全部归零：53dp 阅读地板、16dp 右距、
  8px 上下地板、带侧 8px 漂移余量，Agent 会话页与会话列表一律不再适用。
- **角部避让开关（Corner Avoidance）**：默认**关**（＝贴满，角部行进圆弧、缺角认了）；
  开启时冲进四角圆弧区的行向内收缩到弧线可读边界（沿用既有逐行弧区避让机制），不缺字。
  一个开关同时管会话页与会话列表；入口在主屏 Agent 设置区（与正文档位同处），即时生效、跨重启保留。
- 版心内既有版式语义不变：左对齐、整段优先垂直居中、提问泡右锚版心右侧、会话标识行固定顶部
  （贴缘后即贴屏顶）、字号三档——这些只随视口联动，无独立边距决策。

## User Stories

**版心贴缘**

1. 作为机主，我想让每行多显示约一成字（555→608px），以便少折行、一眼看更多。
2. 作为机主，我想让左侧文字贴住摄像头带的右缘，以便带外空间一像素不浪费。
3. 作为机主，我想让右侧文字贴住屏幕右缘，以便版心吃满无带区。
4. 作为机主，我想让上下也贴缘（会话标识行贴屏顶、末行可滚到贴屏底），以便垂直空间不浪费。
5. 作为机主，我想让提问泡的右锚贴住版心右缘（＝屏缘），以便泡与正文同一套贴缘口径。
6. 作为机主，我想让会话列表与正文用同一套贴缘边距，以便列表开合没有套娃缩进感。
7. 作为机主，我想让通知详情的排版一个字都不变，以便这次改动只影响 Agent 这条线。

**角部避让开关**

8. 作为机主，我想拿到手默认就是最满状态（角部缺字认了），以便不设置也享受最大版心。
9. 作为机主，我想在嫌角上缺字时打开「角部避让」，让角部那几行往里缩到不缺字，以便读得舒服。
10. 作为机主，我想让这一个开关同时管会话页和会话列表，以便不用两边各设一次。
11. 作为机主，我想在主屏 Agent 设置区一处开关、即时生效，以便不用重启背屏。
12. 作为机主，我想让开关状态跨 App 重启保留，以便设一次长期有效。

**机型口径**

13. 作为机主，我想让贴缘口径在别的机型上仍成立——有带贴带缘、无带贴屏缘、带上/带下同理
    避让后贴缘，以便换机不重做。

## Implementation Decisions

- **几何收口仍在 SafeArea 纯函数**：为 Agent 会话页与会话列表新增一个共用的「贴缘视口」出口
  （与 readingViewport / agentReadingViewport 平级的第三入口，或 detailTextViewport 的贴缘入参形态），
  四边 = cutout 避让线（左＝cutout 进深，右/上/下同理），设计 gutter 全 0。
  左缘不再加漂移余量——Agent 层与列表整屏固定落位、不在漂移子树（既有判例注释），8px 纯属多让。
- **Corner Avoidance 是持久化布尔设置**：与 MirrorTextSize 同居 Agent 页呈现偏好存储
  （DataStore，缺键默认 false＝贴满）；主屏 Agent 设置区加一行开关（沿正文档位交互判例）。
- **渲染层零决策照单执行**：Agent 会话页与会话列表的视口来源换成贴缘出口；
  既有逐行弧区避让（首尾行按实际行宽反算圆弧边界）由开关门控——关＝不做弧区内缩（缺角即缺角），
  开＝现状行为。会话标识行、提问泡、滚动视口随新视口联动。
- **Detail View 调用链一条不动**：readingViewport 与 8px 右距地板仍属 Detail 与（改动前的）
  通知路径；共用渲染件按页分流的既有边界继续成立。
- 防烧屏漂移机制本身不动（Dashboard 图标/通知图标照旧漂移，不在贴缘范围）。

## Testing Decisions

- 好测试只测外部行为：几何纯函数「屏几何 + 开关 → 视口矩形/留白」；core「事件 → 事实」。
- **几何 JVM 判例**（沿 DisplaySafeAreaTest 惯例，本机数字直接进断言）：
  - 贴缘视口：904×572 / 左带 296 / r=97 → `[296, 0, 904, 572]`（四边贴缘、左界=带缘）；
  - 开孔在上机型对称判例（顶带上时 top=带上缘避让线，其余贴缘）；
  - 整列角部内缩：贴屏缘列收一个半径（本机 97）、直线区列收 0；`flushReadingViewport(cornerAvoidance)`
    开档＝基本形态上下各让半径（顶带机型含开孔线合成）；
  - 开关关：角部行的留白不含弧区内缩（行框可越弧线）；开关开：弧区内缩回归既有判例数值。
- **core JVM 判例**：默认关、切换无副作用、同值幂等（沿 MirrorTextSizeChanged 判例）。
- **存储层**（落地回填修正）：仓内 DataStore 设置（textSize/alerts/approve）本无 JVM 判例
  先例（Context 依赖、无 Robolectric），本次同样不另起炉灶——缺键默认值与 core 常量同源
  （`CORNER_AVOIDANCE_DEFAULT`），core 侧判例已钉死默认档；幂等由事件判例覆盖。
- 渲染参数判例（AgentMirrorParamsTest）随 RIGHT_INSET 退役改口径；AgentPickerParamsTest 的
  556px 判例是纯函数输入、保留，类 KDoc 基准改贴缘口径。
- 实机验收：截图量左缘 296、右/上/下 0；关开关肉眼确认角部缺角、开开关确认不缺。

## Out of Scope

- Detail View、Icon Set、充电数字、通知图标的一切边距与落位。
- 字号三档、行距、滚动/回看策略、提问泡配色——只随视口联动。
- 背景层与充电水位（早已铺满含带，无变化）。
- 防烧屏漂移的幅度与调度。
- 跨会话翻页、搜索等既有红线边界。

## Further Notes

- 默认档取舍已留痕：缺角（读性问题）换每行约 +9.5% 字宽，机主知情拍板「默认贴满」；
  嫌缺字随时去主屏设置开「角部避让」。
- 版心左界 296 依赖运行时 DisplayCutout 读数，非硬编码机型数字——换机自动重算。
- 落地口径两处细化（review 2026-09-30）：
  - **空态说明与批准失败提示**（Agent 页上的单行居中文案）随贴缘口径，但**不进开关门控**——
    居中短文案实际行宽远离角块，门控只管阅读列（正文/列表），为它引入逐行判据不值。
  - **正文左缘内缩改收宽**：spec 0017 时代标识行内缩靠「整列平移」（右距 16dp 有富余），
    贴缘后右缘即屏缘、平移必出屏——改为右缘钉死屏缘、左缘内缩收宽，提问泡右锚仍贴屏缘（story 5）。
