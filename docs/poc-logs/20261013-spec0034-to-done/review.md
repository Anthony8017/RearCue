## Spec

1 项代码问题：

- P2：普通剪贴板检查在实际读取前就记录 timestamp；随后 primaryClip 返回 null 或抛 SecurityException 时，同 timestamp 在焦点恢复后被跳过。规格要求前台检测新内容且在获得焦点后检查，应成功读取后才提交 timestamp，失败保留重试机会。首次机会有独立状态，普通新内容缺少此保护。

其余静态核对符合：配置与开关加载、关闭和已连接条件优先、首次越过去重、安装期 noBackup 独立标记、格式先筛、旧 IO 失效、真实连接才提示、主页状态唯一、四入口和设置归位。APK 更新按新安装期处理已在实现证据明确，未判为独立缺陷。

默认/大字体、安全区、设置真实持久化、安装恢复、手机与生产桥部署仍无设备证据；#373、#375 相关 AC 保持未完成，不用未验收项虚构代码错误。
