## [F] 真实使用路径的两个阻断条件（→ 票 #6：保活 / 自启动）

**F1 后台被冻结**：HyperOS `GreezeManager` 在应用退到后台时冻结 uid，冻结期间通知事件不到达
（`cgroup.freeze=1`），解冻后才一次性补投：

```
09-22 08:01:23.346  5157  8991 D GreezeManager: FZ uid = 10332 reason =tobg success !
$ cat /sys/fs/cgroup/apps/uid_10332/pid_22005/cgroup.freeze   → 1
09-22 08:00:03.901  5157  8991 D GreezeManager: THAW uid = 10332 pid = [ 22005 ]  reason : Activity Start caller : 1
（冻结期间发的 e7c/e7e/e7f 通知无任何 RearCue 事件；THAW 后同毫秒补投 posted/removed 一串）
```

**F2 进程死亡后系统拒绝重绑监听**（MIUI 自启动白名单）：

```
09-22 08:03:19.092  5157  5157 I AutoStartManagerService: MIUILOG- Reject service :Intent { act=android.service.notification.NotificationListenerService cmp=com.rearcue.poc/.notify.RearNotificationListener (has extras) } userId : 0 uid : 10332
09-22 08:03:19.093  5157  5157 W NotificationListeners: AutStart Unable to bind notification listener service: Intent { act=android.service.notification.NotificationListenerService cmp=com.rearcue.poc/.notify.RearNotificationListener (has extras) }
```

复现方式：`run-as com.rearcue.poc kill -9 <pid>` 杀掉进程后发通知 → 系统不重绑（无日志、无上屏）；
把通知使用权关/开一次（`cmd notification disallow_listener` + `allow_listener`）后可立即恢复上屏。
`cmd appops set com.rearcue.poc AUTO_START allow` 在本机无效（`Error: Unknown operation string: AUTO_START`），
需要用户在 MIUI 设置里给本应用开「自启动」。
