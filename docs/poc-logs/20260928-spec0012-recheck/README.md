# Spec 0012 返修：桌面尺寸、角标落点与两种详情

日期：2026-09-28。用户否决首版验收，明确以桌面右下方 ChatGPT、飞书、RearCue 的独立大图标为大小参照，并确认通知正文和 Codex／Claude 任务内容两种详情都需居中。PR #127 保持草稿，等待用户复验；本记录不宣布最终视觉验收通过。

## 原因

1. **充电场景没有达到尺寸目标。** 首版在非充电时约 156px，实际充电时约 114px。旧代码把不足六个图标也按六格加 +N 的完整预留盒计算，再塞进保守安全矩形并避让电量；目标盒为 `856×618`，缩放约 `0.42071`。之前只强调非充电尺寸改善，漏掉了用户常用的充电场景。
2. **角标落点验收遗漏。** 桌面飞书的角标向图标右上外探 18px；首版角标整个放在图标内部，相对桌面比例偏左下约 16px。只对比底片色彩和字号无法证明位置正确。
3. **详情范围理解过窄。** 首版将 Agent Mirror 排除，任务正文仍使用上下 32dp 和左对齐；用户此次明确两种详情都包括。通知样本原来已逐行居中，代码核对未发现通知测量与绘制样式不一致，不能据此否定用户看到的问题；实际通知案例仍由用户复验。

设备安装包哈希在返修前与首版构建一致，已排除装错包这一解释。原目录 `20260928-spec0012-notification-visuals` 的 PASS 结论已撤回，其数据仅作历史证据。

## 修正

- 单条、多条和充电统一以背屏约 162px 为图标目标；每行最多三格、最多六图标，尺寸由实际几何决定，不再被空行和空 +N 预留压小。
- 角标按桌面比例向右上外探约 16px，完整多位数字向左加宽。实际可见包围盒包含角标外探，仍避相机带和圆角。
- 电量字号与横向位置不变，纵向下移 37px，给六图标让出空间；充电时 +N 在网格下方、电量左侧剩余区域居中。
- `CenteredReadingText` 成为通知详情与 Agent Mirror 的共同版式：逐行水平居中、短内容整体垂直居中、上下最小 8 物理 px，按实际首尾行局部避让圆角。通知从开头进入；Agent 保留滚底跟随、上滑暂停和恢复按钮。
